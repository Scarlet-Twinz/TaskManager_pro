# Academix Pro

A lightweight university GPA calculator for the 5.0 grading scale.

## Overview

Academix Pro lets students enter course codes, credit units, and grades, add additional courses, and calculate their GPA/CGPA through a simple browser-based interface.

## Features

- Add multiple courses
- Enter course codes and credit units
- Select grades from A (5) through F (0)
- Calculate the resulting GPA/CGPA
- Responsive browser-based interface
- No backend or installation required

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Run Locally

Clone the repository and open `index.html` in a modern web browser.

```bash
git clone https://github.com/Scarlet-Twinz/TaskManager_pro.git
cd TaskManager_pro
```

Then open `index.html` directly, or serve the folder with a local static server.

The repository name is `TaskManager_pro`, but the application itself is titled **Academix Pro** and is focused on GPA calculation.
